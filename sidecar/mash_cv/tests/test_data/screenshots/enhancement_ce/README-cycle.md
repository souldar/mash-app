# 循环搓丸子截图

CN 客户端 1920×1080 现场截图，供离线回归使用，不依赖设备或 `.screenshots/`。

- `cycle_target_list.png`：底卡列表，包含未锁定 50/55 与已锁定 53/55 等卡片，说明启用已强化选材前需要保护现有成品。
- `cycle_auto_selected.png`：游戏自动选择 19 张素材后的主页面；素材数可能受经验上限限制，不应要求 20 张。
- `cycle_material_selected.png`：七列素材列表，完整可见选中序号 8–19；上方 1–7 所在行被裁切，不应作为完整卡片识别。
- `cycle_recommend_confirm.png`：开启已强化素材后出现的推荐对象确认，不是实际强化确认。

`selection_number_1` 至 `19` 模板来自现场选中标记；`20` 由同字体数字组合，仍待真实截图验证。1280 宽度回归允许不确定的序号返回未知，不允许错认。

截图采集期间仅执行可取消的选材和导航，没有实际强化。
